# Картинки для сообщений бота

Здесь лежат снимки, которые бот отправляет вместе с сообщениями.
**Чтобы поставить свои — просто замените файлы, сохранив имена.**
Ничего в коде менять не нужно.

| Файл | Где показывается |
| --- | --- |
| `door-catalog.jpg` | «Я ищу специалиста» — первая дверь в `/start` |
| `door-apply.jpg` | «Я оказываю услуги» |
| `door-market.jpg` | «Купи-продай» |
| `door-wanted.jpg` | «Люди ищут прямо сейчас» |
| `market.jpg` | Ответ на команду `/market` |
| `help.jpg` | Ответ на команду `/help` |

## Требования к снимкам

- **Формат** — JPEG, имя ровно как в таблице.
- **Размер** — от 800 до 1600 точек по ширине. Меньше 800 Telegram
  размывает, больше 1600 бессмысленно: он всё равно пережмёт.
- **Пропорции** — примерно 16:9 (например 1280×720). Квадратные и
  вертикальные снимки Telegram обрежет по краям, и часть картинки
  пропадёт.
- **Вес** — до 10 МБ, но лучше держать в пределах 300 КБ: сообщение
  будет открываться быстрее.

Текст на картинке не обязателен — подпись под ней бот добавляет сам.
Если текст всё же есть, держите его подальше от краёв: на узких
экранах Telegram подрезает картинку по бокам.

## Как обновить на сервере

1. Положите свои файлы сюда, сохранив имена.
2. Отправьте изменения в репозиторий.
3. На сервере: `cd /opt/tgspec && ./scripts/deploy.sh`

Бот запоминает идентификатор загруженного снимка, чтобы не заливать
одно и то же по кругу. После замены файлов он перезапускается вместе
со сборкой, память очищается, и новые картинки уходят с первого раза.

## Вернуть нарисованные

Файлы в этой папке созданы скриптом `scripts/bot-images.mjs` — он рисует
их в оформлении приложения. Тексты и значки лежат прямо в нём.
Запуск перезапишет все шесть файлов, поэтому свои снимки держите
где-нибудь ещё, иначе они пропадут.
