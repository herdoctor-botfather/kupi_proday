# С чего продолжить

Записка на случай, если между сессиями прошло время или работа идёт
с другого компьютера. Подробности — в [README](README.md) и [docs/](docs/).

Последняя правка этой записки: 18 октября 2026.

## Где всё живёт

Проект работает в продакшене, на ноутбуке больше ничего поднимать не нужно.

| Что | Где |
| --- | --- |
| Сервер | Timeweb, подключение `ssh tgspec` (настройки — в `~/.ssh/config` на рабочей машине) |
| Mini App | https://pokupaika.duckdns.org |
| Админка | https://pokupaika-admin.duckdns.org |
| Бот | @SJ_Notif_bot |
| Службы | docker compose: `api`, `bot`, `db` (PostgreSQL 17), `web` (Caddy) |
| Фотографии | том `tgspec_uploads`, раздаёт API (`STORAGE_DRIVER=local`) |

Код — в GitHub: `git@github.com:herdoctor-botfather/kupi_proday.git`.
Работать можно с нескольких машин: перед работой `git pull`, после `git push`.

## Выкладка

```bash
ssh tgspec "cd /opt/tgspec && ./scripts/deploy.sh"
```

Скрипт забирает свежий код, пересобирает образы и поднимает службы.
Если сборка или запуск не удались — возвращает прежнее состояние.
Когда ничего не менялось, а пересобрать нужно, — ключ `--force`.

Связь с сервером иногда проседает на десятки секунд, поэтому выкладку
надёжнее запускать в фоне **на самом сервере**, чтобы обрыв её не прервал:

```bash
ssh tgspec "cd /opt/tgspec && (setsid ./scripts/deploy.sh > /tmp/deploy.log 2>&1 < /dev/null &)"
# потом смотреть: ssh tgspec "tail -3 /tmp/deploy.log"
```

### Изменения схемы базы

Миграции Prisma на проде не применяются автоматически. Порядок:

1. `ssh tgspec "cd /opt/tgspec && bash scripts/backup.sh"` — свежая копия.
2. `ssh tgspec "cd /opt/tgspec && docker build --target build -t tgspec-tools ."`
3. Применить diff скриптом в `/tmp/apply-*.sh` (он отказывается выполнять DROP).

### Скрипты данных

Запускаются во временном контейнере. **Адрес базы берут у работающего API**,
потому что в `.env` указан `localhost`, недоступный изнутри контейнера:

```bash
ssh tgspec 'cd /opt/tgspec && URL=$(docker exec tgspec-api-1 printenv DATABASE_URL); \
  docker run --rm --network tgspec_default -e DATABASE_URL="$URL" tgspec-tools \
  npx ts-node --transpile-only apps/api/prisma/apply-category-tree.ts'
```

Так же применяются `apply-category-attributes.ts` (он же удаляет
характеристики, убранные из описания, но только незаполненные).

## Резервные копии

- Снимаются каждую ночь в 4:17 (cron), лежат в `/opt/tgspec-backups`, хранятся 14 дней.
- База и фотографии — отдельными файлами.
- Копия уходит **владельцу в Telegram зашифрованной**; пароль задан
  в настройках сервера и хранится у владельца отдельно от копий.
  Расшифровка — командой `openssl enc -d -aes-256-cbc -pbkdf2`, порядок
  описан в самом `scripts/backup.sh`.
- Восстановление: `scripts/restore.sh ОТМЕТКА_ВРЕМЕНИ`. Проверено в сентябре:
  развёрнутая копия совпала с рабочей базой построчно.
- `scripts/disk-guard.sh` чистит мусор docker (место на диске кончалось,
  и это роняло PostgreSQL).

## Деньги

Оплата — звёздами Telegram, они приходят на баланс бота. Внутренний кошелёк
(`starsBalance`) — наш учёт; покупка сначала списывается с него, при нехватке
выставляется счёт ровно на недостающее.

**До 1 января 2027 почти всё бесплатно** — пока площадка набирает людей.
Срок задан одной константой `LAUNCH_FREE_UNTIL` в `packages/shared/src/pricing.ts`;
поменять дату — значит вернуть оплату, переписывать ничего не нужно.

| Что | Сейчас | После срока |
| --- | --- | --- |
| Объявления | без ограничений | 3 в месяц бесплатно, дальше 29 ★ |
| Показ анкеты мастера в каталоге | бесплатно | 25 ★ неделя, 40 ★ две, 70 ★ месяц |
| Запросы, вакансии, резюме | бесплатно | бесплатно |
| Продвижение объявления | **50 ★ неделя, 149 ★ месяц** | столько же |
| Рисование картинки | **10 ★** | 10 ★ |

Рисование намеренно оставлено платным: каждая картинка стоит площадке
живых денег у поставщика модели (ProxyAPI), и бесплатное безлимитное
рисование опустошило бы счёт.

При первом одобрении анкеты мастер получает **неделю показа в подарок**
(`SPECIALIST_WELCOME_DAYS`).

## Что сделано

Кроме каталога, барахолки, чата, админки и карты (это было и раньше):

- **Платежи звёздами**: счёт → подтверждение → баланс → списание → кешбэк,
  возврат при неудаче. Проверено живыми оплатами.
- **Объявление по фотографиям**: до пяти снимков, ИИ пишет название,
  описание, подбирает категорию и предлагает цену (подсказкой, не в поле).
- **Карьера**: вакансии и резюме, 16 отраслей, 88 должностей, своя страница
  «Мои вакансии и резюме» (`/career/my`).
- **Срочные вызовы**: экран вызова для заказчика и мастера, список «Вызовы
  для вас», окно времени выбирается днями и получасовыми отрезками.
- **Срочная продажа** — отдельная форма (`/market/sell-urgent`).
- **Подписки на спрос**: «сообщать, когда кто-то ищет такое».
- **Глобальный поиск** на стартовом экране.
- **Выбор города на карте** — через OpenStreetMap (`/api/geo/city`).
- **Категории товаров**: дерево как на Авито, характеристики по шагам,
  306 моделей машин с поколениями, 297 моделей телефонов.
- **Имена без контактов**: @ники, ссылки и телефоны вычищаются везде,
  где имя видят другие.
- **Правила площадки и политика конфиденциальности** (`/terms`, `/privacy`).

## Что стоит помнить

- **`.env` нет в репозитории** и не должно быть: там токен бота, пароль
  базы и ключи поставщиков. Рабочая копия живёт только на сервере.
- **Администраторы** заданы в `ADMIN_TELEGRAM_IDS` на сервере.
- **Ключ Яндекс.Карт работает только на показ карты**: геокодер на него
  отвечает «Invalid api key», поэтому город по точке определяет наш сервер
  через OpenStreetMap, не чаще запроса в секунду и с запоминанием ответов.
- **Диск сервера занят на 71%** (29 ГБ всего). Следить стоит: когда он
  кончился в прошлый раз, упала база.
- **`npm audit fix` не запускать.** Предупреждения npm — шум, а смена версий
  ломает сборку.
- **Windows**: файлы в репозитории с переводами строк LF, git предупреждает
  про CRLF — это нормально и ничего не ломает.
- **Демо-карточки мастеров** заведены администрацией, живых аккаунтов
  за ними нет. Их обложки нарисованы, а не сняты.
